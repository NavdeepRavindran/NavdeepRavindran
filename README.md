<summary><b>⚙️ Setup Notes</b></summary>

**Repository structure**
```
NavdeepRavindran/
├── README.md
└── .github/workflows/
    ├── snake.yml
    └── pacman.yml
```

1. Create a public repo named exactly `NavdeepRavindran`.
2. **Settings → Actions → General → Workflow permissions → Read and write permissions → Save.** Both workflows need this to push to the `output` branch.
3. Copy `snake.yml` and `pacman.yml` into `.github/workflows/`.
4. **Actions tab → select each workflow → Run workflow**, once, to create the `output` branch and generate the first SVGs. Each then updates itself on its own schedule.
5. GitHub Stats now uses the official `github-readme-stats.vercel.app` endpoint with `cache_seconds=86400` to stay well under the rate limit — no third-party mirror involved.

</details>
